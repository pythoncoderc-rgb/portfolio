## Project standards

Across the portfolio I aim for:

- a clear README and quick-start path
- small, understandable architecture
- tests for core behavior
- safe defaults for file-changing tools
- no secrets committed to repositories
- version-control-friendly project layouts
- CI where it adds real value
- licenses and repository metadata that match the project

See [PROJECT_STANDARDS.md](PROJECT_STANDARDS.md) for the checklist used by these repositories.
